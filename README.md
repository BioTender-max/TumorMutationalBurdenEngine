# TumorMutationalBurdenEngine

Tumor mutational burden and microsatellite instability analysis engine for immunotherapy response prediction and biomarker stratification.

## Features

- TMB calculation and TMB-High/Low patient stratification
- Microsatellite instability (MSI) status determination
- Immunotherapy response prediction from genomic biomarkers
- Mutation spectrum and signature decomposition
- Clinical outcome correlation and survival analysis

## Results

200 tumors; Median TMB=2.86 mut/Mb; TMB-High=12%; MSI-H=12%; Response rate TMB-H=58.3%

## Usage

```bash
pip install numpy scipy matplotlib
python tumor_mutational_burden_engine.py
```
